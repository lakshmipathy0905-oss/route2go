# Final Demo Script

This script correlates to the `full_app_walkthrough.mp4` recording in the artifacts directory.

1. **Launch**: App opens cleanly without red-screen exceptions.
2. **Onboarding**: Swipes through initial features.
3. **Home**: Dashboard is populated (or empty-state shown clearly).
4. **Plan Trip**: User selects location.
5. **Route Calculation**: System calls the Edge Function and returns routes.
6. **Budget Tracker**: Financial implications of the route are displayed.
7. **Places & Stays**: POIs are populated along the route corridor.
8. **Itinerary**: Day-by-day plan is automatically generated.
9. **Confirm**: Trip is finalized and saved to the database.
10. **Vehicles**: Garage shows default and added vehicles.
11. **Settings & Profile**: Authentication state, themes, and account settings are accessible.
12. **Admin Dashboard**: Accessible only to accounts with Admin RBAC flags.
